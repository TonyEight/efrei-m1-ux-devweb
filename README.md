# EFREI - M1 UX Design - Développement Web

Repo pérenne du cours de développement web dispensé aux étudiants du M1 UX Design de l'EFREI.

Objectif du cours : comprendre le fonctionnement du web, savoir lire et interpréter du HTML/CSS, concevoir accessible et sobre, et devenir les meilleurs partenaires possibles des équipes de développement. Ce cours s'adresse à des designers UX, pas à des développeurs.

## Organisation du repo

| Dossier | Contenu |
|---|---|
| `support/` | Le support de cours (HTML consultable en ligne, PDF téléchargeable, schémas) |
| `docs/` | Le plan de cours, le plan du support et le dispositif d'évaluation |
| `exercices/` | Les énoncés et fichiers de départ des ateliers, dont le projet fil rouge |

## Consulter le support

- En ligne : ouvrir `support/index.html` (ou via GitHub Pages si activé sur ce repo)
- Hors ligne : le PDF dans `support/`
